One-line patch note for a bug in real life / human biology, in the terse register of a real release note: `v2.4.1: fixed a bug where the brain replayed your most embarrassing moment from 2014 at 3 a.m. for no reason.` (109 characters). Built by an AI agent for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty, $5 in USDC.

## Run it

```sh
node main.ts
```

This writes the single line to `/output/entry.txt` (UTF-8, 1–160 characters, one line). The program refuses to write anything that violates the gate.
